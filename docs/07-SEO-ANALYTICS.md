# SEO and Analytics Requirements

## SEO foundation
- Unique title and description for every indexable page
- Canonical URLs
- XML sitemap
- Robots configuration
- Open Graph and social images
- Structured data where appropriate and truthful
- Breadcrumbs for catalog/article hierarchy
- Stable human-readable slugs
- Redirect map from legacy URLs
- Proper 404 page
- Indexation control for preview/design-system routes

## Migration
Before launch:
1. Export current URL inventory.
2. Map every valuable old URL to its new destination.
3. Add permanent redirects.
4. Preserve or improve page intent and metadata.
5. Verify broken links.
6. Submit updated sitemap after domain switch.

## Analytics
Prepare an abstraction for:
- page views;
- catalog filter use;
- product view;
- where-to-buy interaction;
- marketplace click for non-alcoholic products;
- partner form start;
- partner form submit;
- social link click;
- video/motion engagement only when useful.

Do not include tracking IDs or production analytics credentials in the repository.
