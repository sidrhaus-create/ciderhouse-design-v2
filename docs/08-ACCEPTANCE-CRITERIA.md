# Acceptance Criteria

## Visual
- Looks like a custom Cider House digital platform, not a template.
- Primary palette and family accents are consistent.
- Real packaging remains exact and readable.
- Typography hierarchy is strong.
- Desktop and mobile compositions are both intentional.

## Functional
- All navigation links work.
- Catalog filters work and have meaningful empty states.
- Product pages are data-driven.
- Forms validate and expose success/error states.
- Age gate works with keyboard and touch.
- Where-to-buy supports usable fallback when map data is unavailable.
- Back/forward browser navigation behaves correctly.

## Motion
- Wheel, trackpad, keyboard, and touch scrolling remain functional.
- No long empty areas.
- No frozen page after animation teardown.
- Scroll scenes work forward and backward.
- Mobile uses approved lighter variants.
- Reduced-motion fallback is complete.
- Video reaches its intended final frame.
- No black bars from incorrect media fitting.

## Technical
- Type checking passes.
- Linting passes.
- Production build passes.
- No console errors in normal flows.
- No obvious hydration warnings.
- No horizontal overflow.
- Images use correct dimensions/responsive behavior.
- Layout shifts are controlled.
- Critical routes have metadata.
- Legacy redirects are documented.

## Review output
Every task response must include:
- summary;
- files changed;
- screenshots or preview notes where available;
- tests/checks run;
- assumptions;
- remaining placeholders;
- known issues.
