# Куда загружать материалы

Положите файлы в подпапки согласно `docs/01-ASSET-CHECKLIST.md`.

Минимум для первого визуального этапа:

1. Основной логотип Cider House SVG.
2. Колибри/фирменный знак SVG.
3. Логотипы Double Tree, White Phoenix, Mister Bee и 0%.
4. Файлы шрифтов WOFF2 и информация о лицензии.
5. По одному утверждённому PNG/WebP каждой ключевой бутылки.
6. Три бутылки линейки 0% с прозрачным фоном.
7. Hero desktop video + poster.
8. Hero mobile video + poster.
9. Производственные фотографии.
10. Партнёрские логотипы.

Не добавляйте:
- случайные сгенерированные бутылки;
- файлы с шахматной сеткой вместо прозрачности;
- видео с чёрными полосами;
- старые или неподтверждённые этикетки без пометки.
